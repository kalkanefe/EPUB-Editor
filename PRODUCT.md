# EPUB Edit

<!-- impeccable:product-schema 1 -->

## Platform

Native macOS.

## Purpose

From Finder, a reader can right-click an EPUB and correct its metadata, cover, font, or line spacing. The edited file should open in the reader's existing reading app.

The Finder command is called **Edit**. Finder chooses its position in the contextual menu.

**Fix for Kindle** creates a separate, repaired copy of a reflowable book in one click and reports what changed.

## Interface

Use the current macOS design language. Keep the interaction simple and centered on the selected file.
